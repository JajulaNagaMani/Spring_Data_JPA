# Spring Data JPA Demo

A simple **Spring Boot** project demonstrating how to use **Spring Data JPA** for database operations.

## 🛠️ Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* Postman

## 📌 Features

* Create student records
* Retrieve student records
* Update student records
* Delete student records
* REST API integration with Spring Data JPA
